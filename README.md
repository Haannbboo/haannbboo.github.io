# Hanbo Guo - Personal Portfolio & Website

Modern, responsive personal portfolio website built with **React**, **Chakra UI**, **Emotion CSS**, and **Framer Motion**.

## Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling & UI**: Chakra UI + Emotion CSS
- **Animations**: Framer Motion
- **Icons**: React Icons (FontAwesome & Lucide)
- **Routing**: React Router v6

## Development Setup

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```
